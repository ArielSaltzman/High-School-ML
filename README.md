# Weather Analysis Project

This repository contains Jupyter notebooks that analyze historical weather data. The goal is to extract meaningful insights from weather patterns over time. Two primary notebooks are included: **OldWeather_Project.ipynb** and **Weather_Project.ipynb**.

## Contents

1. **OldWeather_Project.ipynb**  
   This notebook contains the initial analysis of weather data. It explores preliminary methods, visualizations, and findings related to historical weather trends. The project serves as a foundation for deeper analysis in the final project.

2. **Weather_Project.ipynb**  
   The final version of the weather analysis. This notebook builds on the methods from the previous project, refining the approach and providing a more thorough analysis of weather patterns. It incorporates additional data, improved visualization techniques, and more advanced modeling.
